# AI Career Salary Prediction and Job Market Analytics

A machine learning project that predicts salary ranges based on job role, 
experience level, industry, and education using structured job market data.

## What it does
- Cleans and prepares job market data
- Performs exploratory data analysis (EDA)
- Builds a predictive model for salary estimation
- Interprets results to identify trends across roles and industries

## Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## How to run
Open `salary_prediction.ipynb` in Google Colab or Jupyter Notebook and run all cells.
